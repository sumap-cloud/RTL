# R10_Pywin_Automation
R10 Stores QA Automation repo - Pywinauto

## Setup on a New Machine
See **[Documentation/NEW_MACHINE_SETUP.md](Documentation/NEW_MACHINE_SETUP.md)** for complete step-by-step instructions to set up this project on a fresh/rebuilt Windows machine.

## Quick Start
1. Clone this repo to `C:\Pywin\RTL Automation`
2. Install Python 3.12.4, Tesseract OCR 5.5.0, and Microsoft Edge
3. Run `python -m venv .` inside the repo folder
4. Install packages: `Scripts\pip.exe install -r Offline_lib\requirements.txt`
5. Double-click `run_tests.bat` to run tests
